# Alamuru Sai Sushrutha - Developer Portfolio

A production-ready, ultra-premium, recruiter-friendly developer portfolio website built for **Alamuru Sai Sushrutha**, a B.Tech Artificial Intelligence & Data Science student.

## 🚀 Features

- **Theme System**: Dark theme by default with optional light theme toggle.
- **Glassmorphism UI**: Custom blur panels, neon borders, and glowing gradient backgrounds.
- **Dynamic Typing Banner**: Rotates through core roles (Java Developer, Python Developer, AI & DS Student, etc.).
- **Single Source Data**: All content editable from `src/data/portfolioData.ts`.
- **Open Source Analytics**: GitHub statistics dashboard with contribution graph, language breakdown, and featured projects.
- **Interactive Projects Modal**: View detailed specs, architecture, features, and direct repository links.
- **Academic Achievement Spotlight**: Highlight banner for ICCIASH 2024 Research Paper presentation.
- **Zero Photographs**: Uses dynamic HTML5 Canvas particle physics, glowing blobs, and developer graphics.
- **Direct Contact Cards**: Clean social & email glassmorphism cards (No contact forms).

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite 6
- **Styling**: Tailwind CSS + Glassmorphism Utilities
- **Animations**: Framer Motion 11
- **Icons**: Lucide React

## ⚡ Quick Start

1. Clone or extract project into local folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run local development server:
   ```bash
   npm run dev
   ```
4. Build production bundle:
   ```bash
   npm run build
   ```
